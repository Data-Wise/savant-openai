# Simulation mode

Before interpreting metrics, check:

- every design cell is present and complete;
- failed or non-converged replications are counted explicitly;
- seed, software versions, and code are recorded;
- bias, RMSE, coverage, power, and MCSE use the designed denominator;
- the primary method is compared with an independent check;
- output artifacts are non-clobbering and traceable to the design.
