# Proof mode

Check structure before algebra:

- define every symbol and quantifier;
- separate identifying assumptions from regularity assumptions;
- verify each load-bearing implication;
- test boundary cases and possible counterexamples;
- use CAS only for mechanical steps;
- treat unavailable or disagreeing engines as `UNVERIFIED`.

A CAS check validates the submitted expression or step, not the theorem's
assumptions, quantifiers, or prose.
